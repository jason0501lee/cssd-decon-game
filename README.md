# 去污區：病房器械盤包 (CSSD Decontamination Game)

一款像素風的供應中心（CSSD）去污區模擬遊戲，靈感來自 *Probably Stolen*。
病房把用過的治療盤包送到去污區窗口：「請務將器械拿至供應中心去污區做清洗。」
你的工作是清點、檢查、分類、刷洗，最後把器械盒放上清洗車架。

**▶ 線上試玩：** https://jason0501lee.github.io/cssd-decon-game/
（建議用電腦瀏覽器，16:9 畫面，滑鼠＋鍵盤操作）

## 流程

1. **窗口**：開窗收件，12 種病房盤包（K020～K240）隨機送來。
2. **Worktable 清點**：器械一件件跳出來，分到器械類／器皿類，清單自動打勾；布類、敷料丟對桶。
   - 使用單位發現有問題的器械會綁橡皮筋 → 放送修籃（去污區只做送修分類，仍要清洗）。
   - 有環柄的器械依尺寸串上串架（5 吋以上 L、5 吋以下 S）。
3. **Workbench 刷洗**：放進清洗水槽浸泡酵素藥水，再用雙頭刷／管腔刷刷洗；明顯髒污要放大後刷乾淨。
4. **清洗車架**：依內容自動選 L／M／S 器械盒（1L＝2M＝3S），放上三層車架。車架會一盤一盤累積，滿了再推進清洗機——越剛好塞滿越賺。

全程以新台幣計分：正確動作加錢、錯誤與漏檢扣錢，清洗車架依裝載率結算。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| 滑鼠拖曳／點選 | 移動、分類、選取 |
| 右鍵 或 `Z` | 放大檢視器械（Workbench 上：特寫刷洗） |
| `1`～`6` | 器械類、器皿類、布類桶、一般垃圾、TOXIC、送修籃 |
| `L`／`S` | 選串架 |
| `R` | 清洗車架上旋轉器械盒 |
| 💡 提示 | 依目前步驟給提示 |

## 說明

- 盤包內容來自去識別化的清點單（醫院名稱改為「中央人民醫院」）。
- 器械保養與損壞判斷參考 B.Braun / Aesculap《手術器械再處理—功能檢測》與 HSPA 去污清洗流程。
- 單一 HTML 檔，所有像素圖都內嵌，不需伺服器。
